# VEX Static Frontend

ده Frontend فقط: HTML + CSS + JavaScript. مفيش Backend، مفيش Node/npm، ومفيش قاعدة بيانات.

## التشغيل
افتح `index.html` مباشرة أو ارفع الملفات كما هي إلى GitHub.

## GitHub Pages
ارفع `index.html` ومجلد `images` إلى جذر الريبو، ثم:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## التفاعل
المنتجات الخمسة، البحث، الفلترة، تفاصيل المنتج، المقاسات، والسلة تعمل في المتصفح. زر Checkout يجهز الطلب عبر WhatsApp بعد إدخال رقم المتجر الدولي.

ملاحظة: دي واجهة عرض فقط؛ الطلبات والمخزون ليست محفوظة على سيرفر ولا تظهر لأجهزة أخرى.
